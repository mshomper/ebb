# src/app.js split into one start-up file per system (m2-app-split)

Status: Done

The Code Health plan's T4, Matt, October 31, 2026. `src/app.js` was one 2,900-line function that 33 of the last 60 merges edited, so every creature branch collided in it. It is now 86 lines: it runs the list in `src/app/systems.js` in order on one start-up context, then gives back what it always gave. Each system starts in its own small file under `src/app/` (the camp, the hen, fishing, the shore, the zones, the frame loop, the action handler and so on, none over 420 lines). The lists branches kept appending to are lists of their own: the base recipes (`recipes.js`), the small lights that join the camp's (`lights.js`), the frame graph's passes in draw order (`passes.js`). The test links (`?day=`, `?trust=`, `?camp=...`, `?lantern`, `?spring=cave` and the rest) live in `test-links.js` and `test-links-camp.js`. Nothing plays differently: the start-up order is the same, Node 1020 of 1020 and the page's 41 of 41 pass, and the determinism hash is still C43ABA37. `docs/03` says how to add a system's start-up file, and `tools/affected-tests.mjs` counts `src/app/` as the app shell, so a branch that touches one of these files no longer runs the full suite.
