# The islet's mats without bands at a low look (m2-mat-banding)

Status: Done

Matt, November 1, 2026. From the walker's eye the meadow islet's thyme, clover and trefoil mats showed their stacked shell copies as horizontal stripes. There were three causes. First, on medium the gap between copies (1.75 cm for thyme) is wider than a leaf clump, so a low line of sight crossed about 4 cm of ground per gap and saw unrelated slices. Second, each copy had one shade. Third, the copy count changed with distance at each corner, so some squares had tilted copies and faint rings. Now each copy's pixels march down through the gap to the copy below, testing the clump domes in steps no longer than half a clump across the ground. The gaps fill with the domes themselves and the rims stay ragged. From above one step is always enough, so the view from above looks and costs the same as before. The number of steps is the tier's new `matSteps` (low 1, medium 4, high 6, ultra 8, `recipes/quality-tiers.json`). Each mat's recipe gains `flowerR` (flower heads trimmed from 0.34 to 0.24 of a spot, because seen from the side they are now round heads and covered more of the carpet) and `stepLeaf` (a step's reach). The copy count is now one per square, so the rings are gone. The island's seed now reaches the mat shader: before, every island had the same clump pattern. Render only, so the determinism hash does not move. `?matsteps=1` turns the march off for side-by-side checks.
