# The B3 check (m2-b3-review)

Status: Done

`tools/b3-review.html`, the exit check that closes M2, built like the first season check: twelve cards (the meadow islet rising, the turnstones, eels, teal, purple sandpipers and grey seals, the room homes take, flax to the teal hat, the light on the stack, the marker stone, rye and kite, shaping noticed in play, and older saves), each with what to do, what to see, a green Set up link to a throwaway test island and its other test links, Pass and Not yet kept in the browser, notes, and Copy results. The cards' data is in `tools/b3-review-checks.js`; the page is listed in `tools/index.html`.

Each Set up link was opened in the game. Fixes found doing so: `?visit=` on a `?day=` island now waits for the island to finish growing, so the visit is today's and the next morning's hint comes (before, it was written as day -1 and no hint came); `?shape=pond,reeds` sets reeds round the dug pond's edge, so the teal's reedy home can be set up; `?tealhat=worn` puts the teal hat on, to wade in it by the flock. The islet link opens at 16:00 on day 27, because at 17:00 the shoal is too late for the 18:00 low tide and waits for the next morning. A flock comes at its own morning hour once its home has been right for 6 game hours, so the home links open at 2:00.
