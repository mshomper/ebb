# Progress entries

One file per piece of work that lands in `main`, since October 31, 2026. Everything before that is the table in [../progress.md](../progress.md), which is an archive and is never edited again. Each branch adds only its own file here, so two branches never touch the same line. `tools/progress.html` shows the table and these files together, in date order (open it through `play.cmd`).

Name the file by the day the branch is handed off and the branch name: `2026-10-31-m2-test-tooling.md`. The fields are the old table's three columns:

```md
# What the step is called (the-branch-name)

Status: Done

What it gives you, in a paragraph or two, as the table's last column said it.
```
