ebb catch-up bench

Checks that time away gives the same island as time watched, and measures how long catch-up takes. Each run starts from the same new island with four reed seeds planted by the pond, in spring. All tools

How long catch-up takes

One bar per game hour, 7 game days in all, run one hour at a time on the page. Bars over the 25 ms laptop budget per hour (doc 19) are drawn in rust.
