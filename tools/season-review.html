The first season check

The exit check for Phase 2 of the keeper's camp (doc 20, "The first season"). Walk each check, mark it, and copy the results to Claude. Anything not yet right becomes a fix log, as Phase 1's did.

Two ways in. Your own island is saved, so a season can be played over several sittings with the time button at 4x. The test links open throwaway islands that are never saved: each sets up one part of the season so it can be checked in a few minutes.

A season is 14 game days. ?nointro&day=N opens a fresh island N days in with the first evening done (day 10 is late spring, 15 early summer, 29 early autumn, 43 early winter). The island plays those days from day 0 while The island grows shows, a few seconds, so plants have come and spread as if it had been left alone.

Each check's green Set up link opens a test island with that check ready to play in under a minute. On a test island, Settings, Tests has Next morning and Skip a day.
